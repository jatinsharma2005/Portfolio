# Running the portfolio in Replit

This project is the existing React + Vite portfolio. The Replit web workflow
runs `npm run dev`; Vite listens on `0.0.0.0:5000` for the preview.

To run the production checks:

- `npm run lint`
- `npm run build`

The portfolio has no application backend or required runtime secrets. Contact
uses a direct email link.
