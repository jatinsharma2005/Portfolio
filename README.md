# Jatin Kumar — Portfolio

Personal portfolio built with React and Vite.

## Development

Install dependencies and start the local development server:

```sh
npm ci
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

The production build is written to `dist/`.

## Deploying to Vercel

Import this repository into Vercel and use the Vite defaults:

- Build command: `npm run build`
- Output directory: `dist`

The portfolio is a static frontend and does not require a server-side runtime.
